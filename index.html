Sincronización Cloud con Google Sheets

Soporte Activo

Ingresá la URL de tu Google Apps Script para sincronizar automáticamente tus Ventas, Compras y Consignaciones cada vez que se guarden en el sistema.

🛠️ ¿Cómo obtener esta URL en 2 minutos? (Instrucciones)

1. Creá una hoja de cálculo en Google Drive.

2. Andá a Extensiones > Apps Script.

3. Borrá todo el código y pega exactamente esto:

function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName(data.tipo) || ss.insertSheet(data.tipo);
  
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Fecha de Registro", "Tipo Evento", "Detalle JSON"]);
  }
  
  sheet.appendRow([new Date(), data.tipo, JSON.stringify(data.datos)]);
  return ContentService.createTextOutput("Sincronizado");
}

4. Haz clic en Implementar > Nueva implementación.

5. Tipo: Aplicación web. Ejecutar como: Tú. Quién tiene acceso: Cualquiera.

6. Copia la URL de la aplicación web que te da Google y pegala arriba.
